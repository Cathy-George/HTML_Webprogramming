Introduction

For this assignment I designed a one-page website for the Department of Information Technology. The page is placed inside a centred white box on a light green background. A logo and title sit at the top, followed by rounded navigation buttons and six sections: About Us, Academic Programmes, Faculty, Facilities, Student Enquiry and Contact Details. Notepad++ was used to write the code and Google Chrome to test it.

1. Structure of an HTML Document

An HTML file is a set of nested elements. The outer structure written at the start of every page is:

<!DOCTYPE>
The first line of the file. It informs the browser that this is an HTML5 document so that it is displayed correctly.
<html>
Starts and ends the HTML document. All other tags are its children.
<head>
A container for page settings: character encoding, the title and the internal <style> block.
<title>
Defines the title in the browser’s title bar / tab. Only one title is allowed.
<body>
Contains the content that appears in the browser window.

2. Headings, Paragraphs and Formatting

There are six levels of headings. I used <h1> once for the department name and <h2> for every section title, which keeps the outline of the page logical. Paragraphs are enclosed in <p>. The formatting tags used are <strong> for important words, <em> for emphasis, <b> for programme names and <small> for the last-date note inside the notice box.

3. Lists

HTML supports ordered lists (<ol>, numbered) and unordered lists (<ul>, bulleted). The subjects offered by the department are written as an unordered list of six items. The class subjects is used in CSS to change the bullet to a circle and to split the list into two columns.

4. Hyperlinks

A hyperlink is created with the anchor element <a>; its href attribute holds the address. The navigation buttons are internal links to section ids. External links point to our college, SWAYAM and MDN Web Docs; target="_blank" opens them in a new tab. The e-mail address uses mailto:.

5. Images

The <img> tag embeds an image. It is an empty element with two essential attributes: src (location of the image file) and alt (text description for accessibility). The size is set with width and height. Two images are used: the department logo in the header, and an illustration of the lab placed inside <figure> with a <figcaption>.

6. Tables

Tables arrange data in rows and columns. The faculty table uses <table>, a <caption> for its title, <tr> for each row, <th> for the column headings and <td> for the data. It lists five faculty members.

7. Forms

The student enquiry form is created with <form>. The fields are grouped with <fieldset> and titled with <legend>. Each <label> is connected to its input using for and id. Input types text, email and tel collect name, e-mail and phone number; a <select> drop-down gives the course preference and a <textarea> takes a message. type="submit" sends the data and type="reset" clears it.

8. Semantic HTML Elements

Semantic elements have names that describe their role, which makes the page easier to understand for developers, search engines and assistive technologies. The elements used in this website are:

<header>
Top part of the page with the logo, title and motto.
<nav>
Holds the six navigation buttons.
<main>
Encloses the central content of the page; used only once.
<section>
Divides the content into About, Programmes, Faculty, Facilities, Enquiry and Contact.
<aside>
Side information that is related to the content – the admission notice.
<figure>
Self-contained image together with its <figcaption>.
<footer>
Bottom of the page with the copyright line.

Conclusion

This assignment showed that a neat and useful department website can be made with plain HTML and a few lines of CSS. Using semantic elements and proper labels made the code organised and accessible. The complete code has been uploaded to GitHub.
