About Us

The Department of Information Technology was established in the year 2004. The department focuses on software development, networking and emerging technologies such as cloud computing and data analytics.

Notice: Admissions for the academic year 2026–27 are now open. (Last date: 30 November 2026)

Academic Programmes

Programmes offered: B.Tech Information Technology (Intake: 60) and MCA (Intake: 30).

Some of the subjects offered are:

  • Programming in C
  • Object Oriented Programming using Java
  • Software Engineering
  • Cloud Computing
  • Data Analytics
  • Information Security
